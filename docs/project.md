# Project description

Habits is an application for tracking your daily routines. Its main purpose is to help you create your own habits and receive reminders to record your activities. Habits provides an overview of your current goals and statistics that show how well you are progressing.

# Main features

## Creating a habit

User can create a new habit that will be tracked by the application. He specifies:
- Name
- Description
- Frequency *
- End date
- When to get notification to record activity

Frequency - Specifies how often the activities should be logged in order to perceive the habit as "successfull" in a given period. Examples of allowed frequencies:
- N times per day/week/month

## Habits overview

User can view the list of current habits. Each list item contains:
- Name
- Records count
- Current status *

Current status - Informs how well you're progressing with the habit. 
If in last N periods the activities were recorded as expected from the habit definition - the status is 'good'. If 75% - 99% of records were not fulfiled - the status is 'ok', if below 75% 'bad'

User can reorder the list by drag and drop the list items

## Record activity notification

User gets push notifications, with a reminder to record the activities for all active habits. When he clicks the notification he is redirected to the "record activity" function
