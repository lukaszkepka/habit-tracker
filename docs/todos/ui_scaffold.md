# UI scaffold

This file describes the UI scaffolding - the template for the durable icons, menus that are displayed on the top of the other components.

## The top menu

It's placed on the top on the screen vertically - a standard approach used in the mobile apps. 
Contains:

### Current screen name
Placement: left 
Content: Name of the current screen, for example for active_habit it should display "Habits"

### Settings
Placement: right 
Content: Just the icon for settings
On click: should open the settings screen (not implemented yet)

## The bottom menu

It's placed on the bottom on the screen vertically - a standard approach used in the mobile apps. 
It contains the icons that navigate to different screens

### Habits 

Icon: #pick up something
Descriptions: Opens the list of active habits
Navigates to: active_habits screen

### Record 

Icon: #pick up something
Descriptions: Opens a screen to log a new activity for a habit
Navigates to: create habit log screen (not implemented yet)

### History

Icon: #pick up something
Descriptions: Opens a history of activity logs
Navigates to: display habit logs screen (not implemented yet)
